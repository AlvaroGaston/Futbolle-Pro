# ⚽ Futbolle Pro

Un juego de adivinanza de jugadores de fútbol desarrollado con HTML, CSS y JavaScript puro (Vanilla JS).

## 🚀 Características

- Lógica de adivinanza estilo "Wordle".
- Historial de partidas guardado en LocalStorage.
- Formulario de contacto validado 100% con JavaScript.
- Interfaz responsiva y efectos de sonido.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (ES5)
